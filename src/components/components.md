📂 Components Documentation
এই প্রজেক্টের UI এবং লজিককে সহজভাবে ম্যানেজ করার জন্য বিভিন্ন কম্পোনেন্টে ভাগ করা হয়েছে। নিচে ফাইলগুলোর সিরিয়াল এবং তাদের কাজ বর্ণনা করা হলো:

1. # Header.js
- প্রধান কাজ: অ্যাপের উপরের অংশ এবং সেটিংস মেনু নিয়ন্ত্রণ করা।
- Model Status: বর্তমানে কোনো মডেল লোড করা আছে কি না এবং সেটি অনলাইন না অফলাইন তা দেখায়।
- Settings Dropdown: গিয়ার আইকনে ক্লিক করলে একটি মেনু ওপেন হয়।
- Functionalities: * নতুন মডেল অ্যাড বা চেঞ্জ করা।
- System Prompt সেট করা (AI-এর আচরণ পরিবর্তন)।
- Setup Guide দেখা।
- পুরো চ্যাট হিস্ট্রি এবং ফাইল ডিলিট করা (Clear Chat)।

2. # MessageList.js (MessageSystem)
- প্রধান কাজ: চ্যাট স্ক্রিন এবং ইউজার ইনপুট এরিয়া হ্যান্ডেল করা।
- FlatList: সব মেসেজগুলোকে লিস্ট আকারে দেখায় (Inverted মোডে, যাতে নতুন মেসেজ নিচে থাকে)।
- Keyboard Management: কিবোর্ড ওপেন হলে চ্যাট লিস্ট যেন ঢেকে না যায়, তার জন্য KeyboardAvoidingView ব্যবহার করা হয়েছে।
- Input Area: মেসেজ টাইপ করার জায়গা যা টেক্সটের পরিমাণ অনুযায়ী নিজের হাইট পরিবর্তন করতে পারে (inputHeight)।
- Loading State: AI যখন উত্তর জেনারেট করে, তখন সেন্ড বাটনের বদলে একটি লোডিং অ্যানিমেশন দেখায়।

3. # MessageItem.js
- প্রধান কাজ: প্রতিটি একক মেসেজ বাবলের ডিজাইন এবং ফরম্যাটিং।
- Bubble UI: ইউজার এবং AI-এর মেসেজকে আলাদা রঙ এবং অ্যালাইনমেন্টে দেখায়।
- Markdown Support: মেসেজের ভেতর **text** থাকলে সেটিকে বোল্ড (Bold) করে দেখানোর লজিক এখানে আছে।
- Copy Action: প্রতিটি মেসেজের নিচে একটি কপি বাটন থাকে যা দিয়ে টেক্সট ক্লিপবোর্ডে নেওয়া যায়।
- Performance: React.memo ব্যবহার করা হয়েছে যাতে অপ্রয়োজনে মেসেজ বাবল বারবার রেন্ডার না হয়।
